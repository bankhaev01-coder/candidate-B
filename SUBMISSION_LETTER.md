## Запуск

```powershell
python main.py
```

Python 3.11 или новее (проверено на 3.13.4), сторонних библиотек нет. Данные
берутся из `data/`, отчётная дата по умолчанию 10.11.2026; любую другую можно
задать: `python main.py --as-of 30.11.2026 --out-dir out`. Тесты:
`python -m unittest discover -s tests -t .` — 95 тестов, все проходят.

## Отступление от текста задания: инструмент

Задание предлагает работать в Claude Code. Работа велась в другом агентском
окружении — Cline в VS Code (модель `deepseek-v4.1-flash:free`), поэтому
приложенный транскрипт снят не командой `/export`, а машинным экспортом истории
задачи: это тот же дамп диалога, что показывает клиент. Текст сообщений не
редактировался и не сокращался, вызовы инструментов приведены вместе с
результатами; опущены только пустые блоки размышлений модели — содержательного
текста в них нет. Сессия по этому заданию одна, поэтому транскрипт один.
Ключей и паролей в сессии нет: вырезать ничего не потребовалось.

Если нужен транскрипт именно из Claude Code — скажите, пересниму работу в нём.
